## 次に実装すべきもの(優先順)

### 1. サイトトップ刷新 = 一覧+プレビュー(P4 本命)+「一覧画面の機能拡充」

改善案の P4 と「一覧画面の機能拡充」を1つのテーマに統合する。参考実装は
ashiato(`https://github.com/worldnine/ashiato`)。着手時にコードを読む。

すぐ直せる不具合(刷新を待たずに先行してよい):

- **一覧画面で `q` / `^C` で終了できない**。終了キーを効かせる

刷新の要件:

- 左に一覧、右にプレビュー。フォーカスとスクロール位置を明示する
- 80桁ではペイン幅を調整、60桁では単一ペインへ縮退(レスポンシブ)
- **フィルタは `/` キーで開始**(いきなりのインクリメンタルサーチは日本語入力と
  相性が悪い)。ashiato の実装を参考にする
- **ソート機能**: 最終アクセス / 更新日時 / 作成日時 / 被リンク数 / 閲覧数 / タイトル
  (本家のソートメニュー相当。メモに本家 UI のスクショあり)
  - ソート順を「各ページ下部の関連ページ」にも効かせるかは未決
- テロメアにリンクの厚さ(被リンク数?)も反映する — 一覧だけでなく各画面共通の話
- **全文検索の UI 接続**もここに合流させる: `search/query` は api.rs 実装済みで
  UI 未接続。一覧に本文検索モードを足す(改善案「必ず組み込む」)

### 2. 画像の貼り付け

クリップボードの画像を貼り付け → アップロード → 記法挿入。仕様ページ:
[アウトライン編集と画像貼り付けの仕様案](https://scrapbox.io/my-sandbox/アウトライン編集と画像貼り付けの仕様案)

- OS ごとのクリップボード取得ヘルパが要る(改善案4 の記述)
- **未決**: アップロード先。改善案は Gyazo、改善案4 は「Cosense のファイル保管」
  と書かれている。着手前にどちらか決める(Cosense 側なら cosense-cli の
  uploadFile 相当の API を TUI から叩く)

### 3. コメントモードの置き場所(P3 の残り)

- キーバインドが混んできたので、どのモードに属させるかを決め直す
- 前提が変わっている点に注意: **Tab は再編済み**(READ=リンク巡回 /
  EDIT=インデント・表セル / 索引=ペイン切替。PLAN-mode-ux.md 参照)。
  メモの「テーブルが Tab の意味を増やした前提」はさらに更新が要る

### 小粒(隙間にやれるもの)

- Block::Inline(画像と文字が混ざった行)のリンククリック: レンダラが Hit を
  捨てているので拾えない。ピースごとの座標を持たせれば直る(改善案 P4 の残り)
- ヘルプ画面のモード別再構成(READ / EDIT / 一覧 / オーバーレイ)
