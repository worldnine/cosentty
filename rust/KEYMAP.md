# cosense-tui キーマップ

**設計原則: akapen のキー体系を正とし、cosense 固有の概念を akapen の「対応する枠」に割り当てる。**

akapen で身につけた指の動きがそのまま通用することを最優先する。新しい概念（ページリンク、
ページ履歴、ブラウザ）は、akapen で意味的に対応する枠（ファイル移動、ファイル一覧、編集）に
マッピングし、キーを新設しない。

## 起動

```
view <project> [title]                      # title 省略時は最近更新されたページ
view https://scrapbox.io/<project>/<title>#<lineId>   # ブラウザの URL をそのまま。#行ID があればその行にカーソル
```

## 日本語環境（IME）前提の操作体系

akapen と同じ Swift ヘルパ（Carbon TIS、アクセシビリティ権限不要）を内蔵し、
**コマンドモードは常に英数・入力欄は自動で日本語** を実現する：

- 起動時に英数へ強制（j/k 等が IME に食われない）。終了時は起動前の入力ソースを復元
- 入力欄（コメント `c`・挿入 `o`/`O`・行編集 `E`）を開くと**自動で日本語に切替**
  （既定 `--ime jp`。切替不要なら `--ime ascii`、何もしない `--ime off`）
- 入力欄を閉じる（Enter/Esc）と即英数に戻る —— 次の j/k が必ず効く
- 外部の `ime guard` デーモン（akapen のもの）とは suspend ファイルで協調
- ヘルパは `~/.cache/cosense-tui/ime-<hash>` に初回バックグラウンドビルド。
  akapen が同一ソースからビルド済みのヘルパ（`~/.cache/akapen/`）があればそのまま使う
- 万一コマンドモードに全角文字が届いたら「IMEがONのようです」と日本語で案内

入力欄は readline 風の行内編集に対応：`←`/`→`（`^b`/`^f`）カーソル移動 · `^a`/`^e` 行頭/行末 ·
`^w` 直前の語を削除 · `^u` 行頭まで削除 · `Del`/`^d` カーソル位置を削除。
日本語の文を途中から直せる（全消しして打ち直さない）。

## 認証

公式 CLI（`@helpfeel/cosense-cli`）の `cosense login` が保存した認証情報
（`~/.cosense/settings.json`）をそのまま使う。解決順序は CLI と同じ:

1. `COSENSE_PAT` 環境変数
2. `projects[]` の Service Account（origin + project 一致、`x-service-account-access-key`）
3. `users[]` の Personal Access Token（origin 一致、`x-personal-access-token`）
4. `COSENSE_SID` 環境変数（connect.sid cookie、レガシーフォールバック）

起動時のステータス行に `auth: pat` のように表示される。未認証なら公開プロジェクトの
読み取り専用（`cosense login https://scrapbox.io` で有効化）。非公開プロジェクトの閲覧・
編集・スナップショット・ファイル/画像取得のすべてがこの認証を通る。認証情報があっても、
現在のユーザーが閲覧先プロジェクトのメンバーでなければ `read-only` と表示し、EDIT セッション・
新規行・削除・undo/redo・`$EDITOR` 編集には入らない。プロジェクト用 Service Account は編集可とみなす。

**リアルタイム反映（websocket push）**: `connect.sid` で認証しているときは
3秒ポーリングの代わりに websocket push 同期が動く（ステータス行に `sync: ws`）。
scrapbox.io の room に join し、commit イベントを `/socket.io/` の生フレームから
直接受信して行差分を即時適用する（ブラウザでの編集が**1秒以内**に画面へ。未読行は
スクラップの room に join し、commit イベントを `/socket.io/` の生フレームから
直接受信して行差分を即時適用する（ブラウザでの編集が**1秒以内**に画面へ。未読行は
テロメアで青く表示）。自分の編集のエコーは冪等適用で二重化しない。切断時は指数
バックオフで自動復帰。
PAT / Service Account のみの環境では従来どおり `sync: poll` の3秒ポーリング。

## cosense 固有の追加

| 操作 | キー | 挙動 |
|---|---|---|
| **モードレス編集セッション** | `e` / `i` / `o` / `O` / ダブルクリック | cosense web と同じ体験：**キャレット行だけ生ソース表示**、他の行はビューのまま。セッション内は完全モードレス：印字キー=入力、`↑↓`=行移動（離れた dirty 行は自動コミット）、`Enter`=分割/新行（インデント継承。ただし**空の箇条書き項目での Enter はリスト脱出**：その行のスペースを消して真の空行にし、新行はインデントなしで始まる）、行頭`⌫`=前行と結合、行末`Del`=次行を結合、`Tab`/`S-Tab`=インデント、`←→`/`^a`/`^e`/`^w`/`^u`=行内編集、`Esc`=終了。**何行でも続けて編集できる**。lineId はクライアント生成なのでサーバ応答待ちなし（直列キューが背後で順次 commit、`✓` 表示）。確認ゲートはなく、安全網は `u`。衝突（409）は自動再読み込み＋同一 lineId で編集継続、行が消えていたら末尾に救出——**書いた文章は失われない** |
| 行/範囲の削除 | `x` | 即削除（ゲートなし。`u` で一発復元） |
| **ページ全体を $EDITOR で編集** | `^e` | TUI を一時中断してページ全文を `$VISUAL`/`$EDITOR` で開く。保存して閉じると **行単位の LCS diff で最小の ops に変換**（変更行は replace で **lineId を保持**＝パーマリンク・テロメアが生き残る）して即 commit。`u` で丸ごと元に戻せる。タイトル行（1行目）の変更はリネーム |
| **リアルタイム同期** | （自動） | `connect.sid` 認証時は websocket push でブラウザの編集がサブ秒で反映（`sync: ws`）。行差分（insert/update/delete）を既存のコミットガードと同じ規則で適用し、適用できない間はバッファしてガード解放後に順次適用。切断は指数バックオフ（最大30秒）で自動再接続、復帰時は全体再取得で取りこぼしゼロ。自分のTUI編集のエコーも同一アカウントのブラウザ編集も**冪等適用**（同じ id の insert は二重化せず、同一テキストの replace は再適用しない）。差分の連鎖（parentId）が切れたらUIスレッドでネットワークを張らず、バックグラウンドの再同期要求で全文を取り直す（失敗時は上限付きで再試行）。
　push とは独立に**60秒の保険ポーリング**も併走するので、SID が失効して push が繋がらない環境でも web 編集は最悪60秒で反映される（壊れても沈黙しない）。PAT のみは従来どおり3秒ポーリング（`sync: poll`） |
| **貼り付け** | （bracketed paste） | セッション中の複数行ペーストは**その場で本物の複数行**になる（1つの insert op、キャレットは最終行末尾へ） |
| **タイムマシン** | `←` / `→` / `Esc` | `←` で過去のスナップショット（Page history、サーバ保持）へ、`→` で新しい方へ、最新を越えると NOW（生ページ）に復帰。`Esc` で即 NOW。履史閲覧中はヘッダが黄色になり `⏪ n/N · 日時` を表示、編集・コメントは読み取り専用。行ごとの更新者/時刻（`t`）は過去版でも動く。スナップショットはキャッシュされスクラブは即座 |
| **関連ページリスト** | （本文枠の下に常時表示） | cosense 本体と同じく、**本文枠を一度閉じた下側（枠外）**に `Links`（1-hop: 順リンク＋被リンク）・**リンクごとの 2 hop グループ**（存在しないページ経由でも成立）・`External links`（プロジェクト横断）を描画。各リンクのガターには、このTUIの訪問記録による細いテロメア（どちらも `▏`）を表示し、未読・既読は色だけで区別する。`G` は本文枠の最終行へ移動し、そこから j/k でそのまま Links へ降りていけ、`Enter` で開ける（ステータスは `R n/N` 表記）。view モードのみ、データはページ取得に同梱の `relatedPages` なので追加リクエストなし |
| リンクを開く | `Enter` / `f` | カーソル行のリンクへ。複数あればピッカーを開く。`[/project/ページ]` の**プロジェクト横断リンク**はそのプロジェクトのページを開く。ヘッダは常に `project/ページ`（URL と同じ形）。`[` で戻れる。`^o` のピッカーは今いるプロジェクトのページを一覧する |
| URL を開く | `Enter` / `f` | カーソル行の http(s) リンク（`↗`）を既定のブラウザで開く。`[タイトル URL]` はタイトル表示。gyazo 画像の行では `↗ gyazo` として**画像のページ**（`gyazo.com/<id>`、Teams は `<org>.gyazo.com/<id>`）を開く |
| ファイルを保存 | `Enter` / `f` | カーソル行の添付ファイル（`📎`、`[名前 https://scrapbox.io/files/….pdf]`）を `~/Downloads` に保存して開く。画像以外の拡張子を持つアップロードが対象で、ページリンクと混在する行はピッカーに両方並ぶ |
| ページピッカー | `^o` | 最近更新順。打鍵で絞り込み（移動は ↑↓ / `^n`/`^p`） |

## マウス（akapen 同様）

| 操作 | 挙動 |
|---|---|
| ホイール | **ビューポートだけ**を1行ずつ動かす。カーソルは行位置を保ち、画面外に出てもよい。j/k 等のキー移動で追従が復帰する。オーバーレイ上ではリストのカーソルを動かす |
| 左クリック | その行にカーソルを移動（選択は解除） |
| ドラッグ | 押した行からポインタ下の行までを範囲選択（`v` と同じ選択になる。続けて `c` でコメント） |
| スクロールバー | トラックをクリックでその位置へジャンプ、サムをドラッグでスクラブ（ビューポートのみ移動） |

ページ送りは **カーソルを動かす**（PgUp/PgDn = 1画面分、`^u`/`^d` = 半画面分、いずれも表示行単位で数えてソース行にスナップ）。ビューポートはカーソルに追従する。

## 意図的に「使わない」キー

- `u` 単独での「戻る」 … akapen の `^u`（半ページ上）との混同を避けナビには使わない → `[`。`u` は vim 同様 **undo** に割当
- `1`〜`9` … 数字は将来の count プレフィックスのために温存。複数リンクはピッカーで選ぶ
- `Space` / `b` … `^d` / `^u` と PgDn / PgUp に統一
- `D`（全削除）… 破壊的操作を大文字1キーに置かない。`d` は akapen 同様「カーソル位置の1件削除」

## オーバーレイ共通操作

`j`/`k` 移動 · `Enter` 決定 · `Esc`/`q` 閉じる

（`^o` ページピッカーだけは打鍵がフィルタに入るので、移動は `↑`/`↓` ・ `^n`/`^p`）

## カーソルとモード切替

カーソルは**ソース行**を指す（akapen の `ViewState.cursor` と同じモデル）。折り返しで複数の表示行に
なった行はまとめてハイライトされ、j/k は表示行単位で送って次のソース行にスナップする。
`Tab` で view⇄source を切り替えても同じソース行に留まり、その行の**物理画面行**も維持される。
テーブルは **1行 = 1ソース行** でカーソル・選択・コメントが行単位に効く（セルが折り返しても
その行の帰属を保つ。akapen の tui-markdown と同じ帰属モデル）。罫線は直下の行に帰属する。

## ガター・スクロールバー

view / source とも**ページ本文だけを枠で囲み**、関連ページ一覧は枠を閉じた後の下側へ置く。
READ 中は端末の ANSI `DarkGray` を使った枠を表示し、EDIT セッション中は枠を消す。フッターの
`VIEW` / `EDIT` 表示も併用する。`>` は左枠と同じ列に置き、その右隣にテロメア、半角スペース、
本文の順で配置する。このため、カーソル行でもテロメアは隠れない。カーソル行は ANSI `DarkGray` で、
テロメア列から右側のスクロールバー列まで、枠の内側を一続きに塗る。右側のスクロールバーは内容が
収まるときは表示せず、先頭位置でも上枠と重ならない。source モードはガターと本文の間に行番号が入る。
ヘッダー、フッター、枠、スクロールバー、オーバーレイ、関連ページ一覧には固定 RGB 値を使わない。
`Cyan`、`Green`、`LightBlue`、`DarkGray` などの ANSI パレットを使い、端末テーマの配色に追従する。
本文のリンク、見出し、コードなどには、引き続きシンタックステーマの色を使う。

## 折り返し

本文は表示幅で折り返す（CJK 幅対応、`src/wrap.rs`）。箇条書き（`• `）・コード行の継続行は
**マーカーの右、本文の1文字目の下に揃える**（ぶら下げインデント）。引用（`┃ `）は継続行にも
**縦棒を繰り返す**ので、折り返された引用が1つのブロックとして読める。ネストが深く
継続行の幅が 8 列を切る場合は通常の折り返しに落ちる。source モードは生テキストなので対象外。

## 見出し

米印が多いほど大きい見出し。`[**** ]` 以上 = レベル1、`[*** ]` = 2、`[** ]` = 3、`[* ]` = 4、
ページタイトル（1行目）= レベル1。各レベルの見た目は **テーマの Markdown 見出し
（`markup.heading.N.markdown`）の書式そのまま**（色＋太字/斜体/下線）。akapen で同じテーマの
Markdown を開いたときと同じ見え方になる。テーマが書式を指定していないレベルだけ、akapen と同じ
構造的な修飾（1: 太字＋下線 · 2: 太字 · 3: 太字＋斜体 · 4: 斜体）を補う。
先頭空白と見出し記法が同じ行にある場合は、インデント位置に `• ` を表示し、本文には見出しの
テーマ書式を適用する。箇条書きと見出しを排他的には扱わない。

`--theme NAME` は本文全体に効く（akapen 同様）。コードブロックのハイライトに加え、見出し・リンク・
引用・`code:` ラベルの色をテーマの **Markdown スコープ**から引く（`[**** ]`〜`[* ]` → `markup.heading.1..4`、
リンク/URL/ハッシュタグ → `markup.underline.link`、引用 → `markup.quote`、`code:` → `markup.raw.inline`）。
テーマにそのスコープの定義がない構文は、端末背景（OSC 11 で自動判定、`--light`/`--dark` で強制）に
合わせた既定色に落ちる。見出しは書式ごと、それ以外は色だけを借りる。
テロメア・カーソル・選択の色はテーマに依存しない。

## テロメア（行の鮮度）

各行の左端1列（ガター）に、Scrapbox 同様のテロメアを表示する。**太さ = 編集の新しさ、色 = 自分が既読か**。

- **未読行**（自分がそのページを最後に開いた後に編集された行、初めて開くページの全行）: **経過時間に関係なく青**。古いほど少し落ち着くが、グレーにはならない
- **既読行**: 太さはそのまま、色はグレー（1年超はさらに薄いグレー）
- 初めて開くページは全行未読（Scrapbox と同じ）。ヘッダに `· first visit`、再訪時は `· N new` と出る

「最後に開いた時刻」は Cosense API の `lastAccessed`（ブラウザでの閲覧）と、この viewer のローカル記録
（`$XDG_STATE_HOME/cosense-tui/visits.json`、既定 `~/.local/state/…`）の新しい方を使う。<br>view / source どちらのモードでも表示される。

段階（太→細）: `█` `<1h` · `▊` `<1d` · `▌` `<1w` · `▎` `<30d` · `▏` `<1y` · `▏` それ以上<br>いずれも1セル幅・左寄せのブロック要素なので、本文の幅は変わらず左端も一直線に揃う。

## 画像読み込み

画像は**バックグラウンドで並行ダウンロード・デコード・端末プロトコルへエンコード**される
（メインスレッドは受け取って差し込むだけなので、読み込み中も操作は止まらない）。ページは即座に読め、届いた画像から
順に差し替わる（未到着の間は `□ loading image…` のプレースホルダが場所を確保）。
gyazo に加え、任意の http(s) 画像 URL（拡張子つき）とリンク付き画像 `[href 画像URL]` に対応。
