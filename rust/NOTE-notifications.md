# NOTE: 通知の4段階(2026-09-03)

トースト導入(PLAN-next.md 4.)の直後、「status から動かしたもの全部」を同じ黄色い
バナーにしていたので、`→ ページ名` や `view` のような、画面を見れば分かることまで
強調されていた。通知を**中身の種別**で5つに分け、**見せ方**を4段階にして
割り当て直した。実装は `view/toast.rs`(`App::note` / `toast` / `toast_err`)。

## 見せ方の4段階

| 段 | 呼び方 | 出る場所 | 寿命 | 意味 |
|---|---|---|---|---|
| 無音 | (呼ばない) | — | — | 画面自体が答えている |
| 薄く | `app.note(msg)` | フッターのヒント欄。status があればその後ろに ` · ` で続く | 4秒 | 気になった人が見れば分かる程度 |
| 黄バナー | `app.toast(msg)` | フッターの1行上、中央寄せ | 4秒(Esc で即消え) | 読んでもらう必要がある |
| 赤バナー | `app.toast_err(msg)` | 同上、赤・太字 | 8秒(Esc で即消え) | 失敗。見逃されてはいけない |

**status(`app.status`)は通知ではない**。「いま何であるか」(選択中・履歴位置・
アップロード中・コミット処理停止・起動時の認証要約)を、状態が変わるまで出す場所。
note はその後ろに乗り、トーストは別の行に出るので、どちらも status を押しのけない。

## 種別 → 段

### 1. 操作の結果確認 → 無音 か 薄く

画面に結果が見えるものは**無音**:
ページ遷移(`→ ページ名`。ヘッダのタイトルが変わる)、`view`/`source`(フッターのタグ)、
`選択を解除しました`(帯が消える)、コメント入力の `キャンセルしました`、履歴から
`最新` へ戻る(⏪ バッジが消える)、`移動モードを抜けました（変更なし）`(MOVE ヒントが消える)。

画面に見えない、または次の一手を添えたいものは**薄く**:
`✓ 行3`(コミット成功。行を書くたびに出るので、バナーにすると一番うるさい)、
`✓ copied` / `✓ コメント N 件をコピー`(クリップボードは見えない)、`保存しました …`、
`開きました …`、`取り消しました（あと N 件）` / `やり直しました`、`✓ 1行削除 · ^z で戻せます`、
`✓ 完了`(EDIT を抜けた)、`✓ ページを作成しました`、`✓ エディタの変更を N 件コミット`、
コメントを保存/削除/空で破棄、`shot.png を貼りました (gcs)`、`見出し レベル2（^t でさらに）`、
アウトライン操作の完了(`✓ 移動 …`)、`アウトライン操作を取り消しました`(^g のあとに別のキー)、
`N 行目のコメント`(クリックで巡回)。

### 2. 境界・何も起きなかった → 薄く

`ページの先頭です` / `末尾です`、`戻る/進む先の履歴はありません`、`この行にリンクは
ありません`、`この行にコメントはありません`、`これ以上コメントはありません`、
`コピーするものがありません`、`取り消せる/やり直せる編集がありません`、`すでに最新です`、
`最も古い履歴です`、`このページに履歴はありません`、`変更はありません`(外部エディタ)、
`リンクのある行がありません（ソース表示は s）`、`割り当てのないキー`、
`「x」は本文にありません`(索引の本文検索)。
vim が `Already at oldest change` をコマンドラインに地味に出すのと同じ重さ。

### 3. 拒否と案内 → 黄バナー

「ここではできない、こうすればできる」。
`貼り付けは編集中に — e / i / o で入ってから`、`削除は編集中に — …`、
`関連ページの行は編集/選択できません`、`履歴を表示中 — 読み取り専用（Esc で最新へ）`、
`タイトル行は削除/アウトライン操作できません`、`選択中はブロック操作できません — Esc で解除`、
`移動モード中 — Esc/Enter で確定してから`、`ブロックを動かすには Esc で編集を抜けて m`、
`IMEがONのようです — 英数に切り替えてください` / `英数に戻しました`、
`未作成のページ — e / o で書き始めると作成されます`、`検索結果は関連度順です（^u で一覧へ）`、
`画像は編集中に貼ってください`、画像を貼ったが `元の行が無くなっていたので末尾に置きました`。

### 4. 失敗 → 赤バナー

`コミットに失敗しました`、`開けません: /project/title`、ダウンロード/保存/アップロードの失敗、
`読み直しに失敗しました`、`履歴(一覧)を取得できません`、`ページ一覧/メンバー一覧を取得できません`、
`このプロジェクトでは編集権限がありません`、`読み取り専用なので画像を上げられません`、
`エディタが中断しました`、`一時ファイルを作れません`、`設定ファイルを読めませんでした`、
`ページが空になるため中止しました`、`{name} は 100MB を超えています`、`… へ上げるには {var} が要ります`、
`プロジェクトの容量上限`、`アウトライン操作に失敗しました — 変更を戻しました/読み直しました`、
`つかんでいたブロックが見つからないので … 戻しました`、`コミット処理が停止しました`(これは
status: 状態が続く)。

### 5. 自分がしていないのに起きたこと → 内容次第

読者の手元が変わるものは**黄バナー**: `他の人がページを更新しました — 読み直しました`、
`… 編集中の行はそのままです`、`編集中の行が他の人に削除されました — 内容はページ末尾に退避`。
内部動作の実況は**薄く**: `⟳ websocket で更新を反映`、`⟳ web側の編集を反映`(poll)、
`⟳ 差分に欠落 — 再同期します`、`全同期 …`、`ws: 接続済み` / `切断 — 再接続します`
(同期状態は型付きでフッターに常駐しているので、文言は補足)。図が描けなかった
`diagram: …（ソースを表示します）` も薄く(以前の `web_notice` はこの段に統合した)。

## 決めていないこと

- コミット失敗は8秒で消えてよいのか。「書いたものがサーバーに無い」状態は
  `web_unsynced` フラグにはあるが、フッターに**状態として**出していない。
  `未同期` の常駐バッジを status/フッターに出すのが筋で、それは 5. ヘッダの整理と
  一緒に見る
- ビープ・フラッシュ(akapen の flash_err)は入れていない
