# SPEC: akapen とのスクロール/カーソル/表示対応の整合

## 背景

cosentty（Rust + ratatui）のビューを akapen（https://github.com/worldnine/akapen）の
モデルに寄せる。現在の実装はカーソルが「表示行インデックス」ベースで、akapen の
「ソース行アンカー」モデルと異なる。下記を実装する。

## akapen の実装事実（参照元）

- `src/view.rs` ViewState:
  - `cursor: usize` は **ソース行番号（0-based）**。表示行とは分離。
  - `source_starts: Vec<usize>` … ソース行 i の**最初の表示行**を引く配列。
    ソース行 i が占める表示行範囲は `source_starts[i] .. source_starts[i+1]`。
  - `cursor_row()` = カーソルのソース行の先頭表示行、`cursor_end_row()` = 末尾表示行。
  - `move_cursor_display(delta)` … 表示行単位で動き、**止まるのは常にソース行**。
  - `keep_cursor_visible(viewport)` … 上方向は先頭行、下方向は末尾行でビューポートを
    追従させる（折り返しやコメントカードで詰まらない）。
- `src/main.rs`:
  - モード切替（Tab）時: `old_cursor = if source_mode { app.cursor } else { app.view.cursor }`
    として**ソース行を引き継ぎ**、さらにカーソル行の**物理画面行**を維持する
    （`replace_view_preserving_cursor` / 行 2193 付近）。
  - 視野サイズ変更時は `cursor_fraction()`（カーソル位置の割合）で相対位置を保つ。
  - ホイールスクロールはビューポートのみ動かし、カーソルは絶対位置を保持。
  - view モードは枠付き（左ボーダー列に gutter マーカー、右にスクロールバー）。

## 変更方針（現実装 = src/bin/view.rs）

現在:
- `App.cursor: usize` は `rows[]` のインデックス（表示行）。→ **ソース行番号に変更**。
- `Row { src: Option<usize> }` は各行がどのソース行由来かを持つ（これは維持・活用）。

### 1. カーソルをソース行アンカーに変更
- `App.cursor` をソース行番号（`0..lines.len()-1`）にする。
- 表示時に `rows.iter().position(r.src()==cursor)` で先頭表示行を求め、
  「そのソース行が占める全表示行」にカーソル背景を付ける（折り返し行も全部ハイライト）。
- j/k の移動: 表示行ベースで隣の表示行に動いたら、その行の `src` にスナップ
  （= 現在と同等の処理を、カーソルをソース行で持つ形に書き換える）。
  要するに `src` が変わるまで行を送り、ソース行を進める。
- g/G: 先頭/末尾のソース行。

### 2. モード切替（Tab）の引き継ぎ
- ソース行で引き継ぐ（現実装と同じ思想なので維持）。
- **加えて**: カーソル行の先頭表示行が切替前後で**同じ物理画面行**に来るよう
  `scroll` を調整する（akapen の `replace_view_preserving_cursor` 相当）。

### 3. スクロール統一
- view / source 両モードで同じスクロール実装（行ベース、現在の `scroll` を維持）。
- カーソル追従は「カーソルのソース行の先頭表示行がビューポート内に入る」を担保
  （下方向は末尾表示行基準、akapen の keep_cursor_visible と同様）。
- マウスホイールスクロール（未実装なら追加）はビューポート優先で、カーソルは動かさない。

### 4. view モードに枠を付ける
- view モード本文を枠で囲む（akapen は罫線枠 + 左右のボーダー列）。
- **左ボーダー列**: 通常時はテロメア（太さ+色のグリフ `█▉▊▋▌▍▎▏`）、
  カーソル行は `>`、コメント行は黄の `▌`（入力中の範囲はシアンの `▌`）を優先表示（2026-09-03 実装）。
- **右ボーダー列**: スクロールバー（位置+サム）。
- 枠の分の列を本文幅から引く。
- source モードは枠なしの現状維持（行番号ガター）。
- テロメアの色分け/太さは `src/theme.rs::telomere()` をそのまま使う。

### 5. テロメアを左辺に
- 上記 4 の左ボーダー列にテロメアを置く。現状の独立した gutter 列（3列）を
  **枠の左辺に統合**し、本文を1〜2列分広げる副作用にする。

## 注意（実装時の落とし穴）

- カーソルのソース行が表示行を持たない（空レンダリング等）ケースのガード。
- 画像行: ソース行1つに対し高さ大。カーソル背景は画像ピクセルに被らないので
  実効上は行マーカーとテロメアのみが効く（akapen も同様）。
- コメントカード（Row::Card）は src を持たない（既存どおり選択対象外）。
- 幅変更時の `cursor_fraction()` 等価（相対位置維持）も入れる。

## 検証

- `cargo build && cargo test` が green（現状 26 tests）。
- 手動: 画像を含むページ/テーブル/折り返し行があるページで、
  ソース⇄view 切替（Tab）時にカーソルの行位置と物理画面行が維持されること。
- テロメアが左ボーダー列に出て、view/source 両モードで表示されること。
